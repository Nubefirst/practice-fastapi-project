# TicketFlow API

Система учета заявок с разграничением прав доступа на базе FastAPI.

## О проекте

TicketFlow API — это backend-приложение для регистрации, обработки и администрирования заявок пользователей.

Проект разработан в рамках учебной практики по направлению подготовки «Информационная безопасность автоматизированных систем».

Основная цель проекта — создание защищенной системы учета заявок с использованием современных технологий разработки веб-приложений.

---

## Основной функционал

### Пользователь

* регистрация в системе;
* авторизация по JWT-токену;
* просмотр собственного профиля;
* создание заявок;
* просмотр списка своих заявок;
* просмотр отдельной заявки.

### Администратор

* просмотр всех пользователей;
* просмотр всех заявок;
* фильтрация заявок;
* назначение исполнителя;
* изменение статуса заявки.

### Аудит действий

Система ведет журналирование критически важных действий:

* создание заявки;
* назначение исполнителя;
* изменение статуса заявки.

Все действия сохраняются в таблице аудита для последующего контроля и анализа.

---

## Информационная безопасность

В проекте реализованы следующие механизмы защиты:

* JWT Authentication;
* Role-Based Access Control (RBAC);
* хеширование паролей с использованием bcrypt;
* разграничение доступа по ролям;
* аудит действий пользователей;
* хранение чувствительных параметров в переменных окружения.

## Запуск проекта

### Локальный запуск

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Применение миграций:

```bash
alembic upgrade head
```

Запуск приложения:

```bash
uvicorn app.main:app --reload
```

Swagger UI:

```text
http://localhost:8000/docs
```

---

## Запуск через Docker

Сборка контейнеров:

```bash
docker compose build
```

Запуск:

```bash
docker compose up
```

Swagger UI:

```text
http://localhost:8000/docs
```

## Реализованные роли

### USER

Доступ:

* регистрация;
* авторизация;
* просмотр профиля;
* создание заявок;
* просмотр собственных заявок.

### ADMIN

Дополнительно имеет доступ:

* ко всем пользователям;
* ко всем заявкам;
* к управлению заявками;
* к журналу аудита.
